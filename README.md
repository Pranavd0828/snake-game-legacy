# Neon Snake: Ultimate Edition

A high-octane, rogue-like snake game featuring a procedural techno soundtrack, beat-reactive visuals, and full mobile support.

![Gameplay Screenshot](gameplay.png)

## 🎮 Features
- **Rogue-like Power-Ups**: Collect temporary abilities like **Slow Motion**, **Magnet**, **Ghost**, and **Double Score**.
- **Audio Visualization**: A custom-built, generative techno sequencer that syncs the entire game world (grid, bloom) to the beat.
- **Mobile Optimized**: Play with precise **Virtual D-Pad** controls or classic **Swipe** gestures on any device.
- **Visuals**: A "Hyper-Modern" neon aesthetic with glassmorphism UI and dynamic lighting.

## 🚀 How to Deploy (GitHub Pages)
This project is ready for instant deployment on GitHub Pages.

1.  Go to your GitHub Repository **Settings**.
2.  Scroll down to the **Pages** section (or find "Pages" in the sidebar).
3.  Under **Source**, select `Deploy from a branch`.
4.  Under **Branch**, select `main` and `/ (root)`.
5.  Click **Save**.

Your game will be live at `https://<your-username>.github.io/<repo-name>/` in a few minutes!

## 🕹️ Controls
- **Desktop**: 
  - `WASD` or `Arrow Keys` to move.
  - `Space` to start/restart.
  - `ESC` to pause.
- **Mobile**:
  - Use the on-screen **D-Pad** or **Swipe** to move.
  - Tap screen to start.
  - Tap the **Pause** button (top-right) to suspend the system.

## 🛠️ Tech Stack
- **Core**: Vanilla HTML5 Canvas & JavaScript (ES6+).
- **Audio**: Web Audio API (No external assets, all procedural).
- **Storage**: `localStorage` for high scores.
